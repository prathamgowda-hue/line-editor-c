# Line Editor Commands

- `INSERT <line_num> <text>`: Inserts text at the specified line number.
- `DELETE <line_num>`: Deletes the line at the specified line number.
- `DISPLAY`: Shows the entire document with line numbers.
- `SAVE <filename>`: Saves the document to a file.
- `LOAD <filename>`: Loads a document from a file.
- `STATS`: Displays total line count and word count.
- `HELP`: Displays command usage.
- `EXIT`: Exits the application.
